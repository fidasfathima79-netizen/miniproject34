# Restaurant Menu Management System

## Description

A command-line based Restaurant Menu Management System developed using Python and SQLite3.

## Features

* User Registration and Login
* Staff and User Roles
* Menu Management
* Order Placement
* Order History
* SQLite Database Storage

## Technologies Used

* Python
* SQLite3

## How to Run

1. Install Python 3.
2. Save the source code as `miniproject1.py`.
3. Open terminal in the project folder.
4. Run:

miniproject1.py

## Database Tables

* user
* menu
* orders
